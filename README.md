# My Social Studies

نسخة ثابتة من منصة My Social Studies.

- جميع فيديوهات الدروس الـ11 مضمّنة داخل `index.html` بصيغة Data URI، لذلك لا يعتمد تشغيلها على مجلد فيديو خارجي.
- الصور/الشخصيات المستخدمة في الواجهة مرسومة SVG داخل الكود، ولا توجد صور خارجية مطلوبة للتشغيل.
- لا توجد شعارات QUREO أو SPRIX أو وزارة التربية والتعليم داخل المنصة.
- لا توجد مكتبات خارجية أو CDN مطلوب للتشغيل.
- مناسبة للرفع كصفحة GitHub Pages ثابتة.

ملاحظة: صور مياو وسوزي الأصلية لم تكن ضمن الملفات المتاحة أثناء هذه النسخة، لذلك الواجهة تستخدم رسومات SVG مضمّنة إلى أن تُرسل الصور الأصلية.
