# My Social Studies — AI Edition

- `site/` = ارفع محتوياته إلى GitHub Pages.
- `worker/` = خادم «اسأل مياو» الحقيقي.
- لا تضع `OPENAI_API_KEY` داخل الموقع أو GitHub Pages.
- الصور المؤقتة لشخصيتي مياو/سوزي مأخوذة من شخصيتي منصة الكيمياء (كيمتشي/نيتشو) ومضمّنة داخل HTML، ويمكن استبدالهما لاحقًا بصور مياو وسوزي الحقيقية.
- الفيديوهات الأساسية للمنصة مضمّنة داخل HTML كما طلبت.
